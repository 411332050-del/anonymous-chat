# 匿名聊天室：畫面設計

> 本文件記錄 `/design` 的設計結果，供實作前端時對照。
> 畫面「有哪些元素、各自的行為」以 `docs/architecture.md` 第 7 節為準；本文件負責「長什麼樣子」。
> 視覺稿（靜態示意，無互動）：https://claude.ai/artifact/LLcS7ytmMYC4BqMHobJ44z （私人連結，需由擁有者開啟或分享）

## 1. 風格

深色、現代聊天軟體。深灰底、柔和對比、圓角氣泡、藍紫色強調。手機優先，電腦版把內容置中。

## 2. 設計變數（實作時應做成 CSS 變數）

### 顏色

| 用途 | 色碼 |
|---|---|
| 頁面背景 | `#141518` |
| 頂部列、輸入區背景 | `#1c1e22` |
| 分隔線、邊框 | `#2a2d33`（較亮的輸入框邊框 `#3a3d45`） |
| 主要文字 | `#e8e9ec` |
| 次要文字（時間、說明） | `#9ba1ac`（較亮 `#c3c7cf`） |
| 強調色（送出鈕、重試鈕、暱稱文字） | 按鈕 `#7c8cff`，按鈕上的字 `#10122b`；暱稱文字 `#aab4ff` |
| 他人訊息氣泡 | 背景 `#2b2d33` |
| 自己的訊息氣泡 | 背景 `#4452c4`，文字白色 |
| 錯誤／失敗 | 邊框與文字 `#ff8a8a`、`#ffb3b3`、`#ff9d9d`；失敗氣泡背景 `#3a1f26` |
| 警告（重新連線、離線） | 橫幅背景 `#3a2f12`、邊框 `#6b5517`、文字 `#ffd98a` |
| 在線小圓點 | `#5fd38d` |
| 停用的按鈕 | 背景 `#2b2d33`、圖示 `#6b707a` |
| 「有 N 則新訊息」按鈕 | 背景 `#2b2f55`、邊框 `#5560c9`、文字 `#d7dcff` |

### 字體與尺寸

- 字體：Noto Sans TC（Google Fonts），後備 `system-ui`。
- 訊息內文 15px、行高 1.5；暱稱與時間 12px；頂部標題手機 18px、電腦 20px；說明文字 13～14px。
- 氣泡圓角：他人 `4px 16px 16px 16px`，自己 `16px 4px 16px 16px`。
- 氣泡最大寬度：手機約 78%，電腦約 70%。
- 觸控目標至少 44px（重試鈕、新訊息鈕）；送出鈕手機 48px、電腦 52px。
- 圖示一律內嵌 SVG 線條圖示，不用 emoji；純裝飾的圖示加 `aria-hidden`。

## 3. 畫面規格

畫布共五個畫面。手機稿尺寸 390×844，電腦稿 1280×800。

### 畫面 A：進入中

- 垂直水平置中：旋轉的載入圖示、標題「正在進入聊天室…」、說明「正在為你準備匿名身分」。
- 底部固定一塊提示（階段一才顯示）：「展示模式：目前訊息只存在你的瀏覽器，不會傳給其他裝置。」階段二移除。

### 畫面 B：聊天大廳

**頂部列**
- 左：標題「匿名聊天室」。右：綠色小圓點加「目前 N 人在線」。
- 手機：暱稱另起一行，「你是：」加強調色暱稱。電腦：暱稱與人數同排靠右。暱稱不可編輯。
- 連線狀態：正常時完全不佔位。`reconnecting` 時，頂部列下方出現警告橫幅「重新連線中…」（附旋轉圖示）。

**訊息區**
- 舊在上、新在下，內容不夠多時貼齊底部。
- 他人訊息：氣泡上方一行「暱稱 · 時間」，靠左。
- 自己的訊息：靠右，氣泡下方一行狀態，不顯示暱稱。
  - 已送出：「時間 · 已送出」。
  - 傳送中：氣泡半透明（不透明度 0.6），下方「傳送中…」。
  - 失敗：氣泡改為失敗樣式（紅色邊框、暗紅底），下方「傳送失敗」加「重試」按鈕（描邊樣式）。
- 最頂端：載入更早訊息時顯示「載入更早的訊息…」加旋轉圖示；已載完時顯示「— 已經是最早的訊息 —」。
- 「有 N 則新訊息」：使用者正在往上看舊訊息時，輸入區上方置中顯示的膠囊按鈕，附向下箭頭，點擊後跳到最底。使用者停在底部時不出現。
- 空狀態：置中的對話圖示加「還沒有人說話，來打個招呼吧」。

**輸入區**
- 輸入框（多行，圓角）、右下角字數計數「N / 500」、旁邊圓形送出鈕。送出鈕用紙飛機圖示。
- 輸入框需有隱藏的標籤文字「輸入訊息」（給讀屏軟體）。
- 提示文字放在輸入框上方一行：
  - 被頻率限制：「發言太快了，請稍等幾秒」（紅色，幾秒後自動消失）。
  - 離線：「目前離線，連線後可再試」（黃色）。
- 超過 500 字：輸入框邊框變紅，下方左側「超過 500 字，請刪減後再送出」，右側計數變紅（例如「512 / 500」），送出鈕停用。
- 離線時：輸入框與送出鈕都停用，輸入框 placeholder 為「連線後才能發言」。
- 內容為空白時：送出鈕停用，不另外提示。
- 鍵盤：Enter 送出、Shift+Enter 換行（電腦）。

**電腦版版面**：頂部列滿版；聊天內容與輸入區置中，最大寬度約 760px。

### 畫面 C：無法連線

- 垂直水平置中：紅色警告圖示、標題「目前無法連線到聊天室」、說明「請檢查網路後再試一次」、強調色「重試」按鈕（高 48px）。
- 點「重試」重新執行進入流程。

## 4. 實作時要注意

- 手機輸入框要避開虛擬鍵盤，不被遮住（`architecture.md` 第 7 節）。
- 設計稿裡的訊息、暱稱、時間與人數都是示範資料，不是真的內容；字串（如提示語）以本文件為準，可再微調。
- 使用真正的 `<button>`、`<textarea>`、`<label>`；只有圖示的按鈕要加 `aria-label`。
- 文字對比以設計稿色碼為準；新增顏色時，一般文字需與底色達 4.5:1。
- 視覺稿是靜態的：動畫（載入旋轉）、捲動行為、狀態切換都要在實作時依 `architecture.md` 的資料流補上。

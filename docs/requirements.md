# 匿名聊天室：需求說明

一個網頁版的**匿名公開聊天室**。打開網址 → 輸入「代號」→ 按「進入聊天室」→ 進到所有人共用的大廳，可以看到大家的訊息，也可以發言。技術與架構見 `architecture.md`，畫面設計見 `design.md`。

## 目標

1. 做出一個真的能用、能公開分享網址的聊天室。
2. 完全免費運行（GitHub Pages ＋ Supabase 免費方案）。
3. 分兩個階段：先做出看得到、點得動的畫面（假服務），再接上真正的後端；第二階段不需要把第一階段重寫。

## 已確認的需求

| 項目 | 決定 |
|---|---|
| 形式 | 一個所有人共用的公開大廳，沒有分房間 |
| 進入方式 | 打開網址先看到進入畫面，輸入代號（去頭尾空白後 1～12 字）並按「進入聊天室」才會連線 |
| 身分 | 名稱＝代號＋系統產生的 3 碼編號（例如「小明#371」）；編號使用者不能自己指定，同一個匿名身分固定不變 |
| 編號保留 | 同一個瀏覽器每次回來編號都相同（代號可重新輸入），直到使用者清除瀏覽器資料 |
| 歷史訊息 | 進入時看到最近約 50 則，往上捲可以載入更早的 |
| 訊息內容 | 純文字，上限 500 字 |
| 發出之後 | 不能編輯、不能刪除 |
| 即時性 | 別人發的訊息即時出現，不用重新整理 |
| 線上人數與名單 | 顯示「目前 N 人在線」，可展開在線名單（完整名稱，自己標「（你）」）；有人進來或離開時顯示短暫提示 |
| 防濫用 | 只做發送頻率限制（每人 10 秒最多 5 則、兩則間隔至少 0.5 秒），超過時顯示「發言太快了」；沒有檢舉、封鎖 |
| 裝置 | 手機與電腦都要好用，畫面自動配合螢幕大小 |

## 新增功能（在畫面上怎麼看到）

| 功能 | 在畫面上怎麼看到 |
|---|---|
| 資料庫強制發送頻率限制 | 連續快速送出訊息，超過限制時顯示「發言太快了，請稍等幾秒」，幾秒後自動消失。 |
| 伺服器端內容清理 | 送出含零寬字元、很多空行或頭尾空白的訊息，顯示的是清理後的版本。 |
| 匿名登入＋資料庫產生的 #編號 | 頂部顯示「你是：小明#371」；重新進入編號不變，無法自己指定。 |
| 往上捲動載入更早的訊息 | 捲到頂載入更早 50 則；載完顯示「已經是最早的訊息」；失敗可按「重試」。 |
| 訊息傳送狀態 | 自己的訊息顯示「傳送中」→「已送出」；失敗顯示「失敗」並可點擊重試。 |
| 表情回應 | 每則訊息下方可以按 👍 ❤️ 😂 😮 😢 🎉；顯示各表情的人數、自己按過的有底色；再點一下收回；別人按的即時出現，重新整理後仍在。 |
| 「正在輸入…」提示 | 在輸入框打字時，其他人在輸入框上方看到「某某 正在輸入…」；停止輸入約 5 秒或送出訊息後消失。 |

### 基本功能（課程必要項目，不算新增功能）

| 功能 | 在畫面上怎麼看到 |
|---|---|
| 收到的訊息先驗證格式才顯示 | 格式不對的訊息不會出現在畫面上；通過的一律以純文字顯示。 |
| 線上名單與進出提示 | 點「目前 N 人在線」展開名單；有人進來或離開時顯示「某某 進來了／離開了」。 |

## 刻意不做

多個房間、私訊、編輯或刪除訊息、自訂表情、圖片與檔案、檢舉與封鎖、管理員後台、訊息自動清除、推播通知。完整清單與理由見 `architecture.md` 第 10 節。

## 已知限制

代號可以重複（編號不同）、訊息永久保存、畫面一次載入 50 則。詳見 `architecture.md` 第 9.4 節。
